## 1. 機器人如何「看懂深度」？空間感知的三大流派

普通相機拍攝的照片只是二維平面矩陣（像素 $u, v$），缺少了關鍵的「距離（深度 $Z$）」。沒有深度資訊，機器手臂就無法得知物件究竟是「一顆近處的小球」還是「一顆遠處的大球」。
為了解鎖 3D 空間感知，學術界與產業界發展出三大核心測距流派：

```
                              ┌─────────────────────────────────────────┐
                              │       機器人 3D 深度感測三大流派         │
                              └────────────────────┬────────────────────┘
                                                   │
         ┌─────────────────────────────────────────┼─────────────────────────────────────────┐
         ▼                                         ▼                                         ▼
   【流派 A：雙目立體視覺】                   【流派 B：單眼幾何推算法】               【流派 C：主動深度相機】
  (Stereo Dual-Vision)                     (Similar Triangles Method)              (RGB-D / LiDAR ToF)
   • 模仿人類左右眼                          • 已知物體物理尺寸 (如球半徑)             • 發射光脈衝/紅外條紋
   • 利用「視差 (Disparity)」                • 成像比例 + 相似三角形比例                • 精準生成 3D 點雲
   • 幾何視角交叉定位                        • 不需額外硬體，運算極快                  • 遠距抗干擾強、免特徵比對
   • (論文 6、論文 7)                         • (論文 2)                                • (論文 2 Intel L515)
```

### 流派 A：雙目立體視覺（Stereo Vision，論文 6、7）
* **原理**：完全模擬人類雙眼的立體視覺機制。將兩台相機水平相隔一基準距離（Baseline $B$）放置。同一個物體在左相機與右相機的成像水平位置會產生微小位移，這個位移就稱為**視差（Disparity, $d = x_L - x_R$）**。
* **數學關係**：
  $$\text{深度 } Z = \frac{f \cdot B}{d}$$
  其中 $f$ 為相機焦距。物體離我們越近，左右兩眼的視差 $d$ 越大；物體越遠，視差越小。
* **優點**：架構經典，適用於戶外與各類明亮場景。
* **工程挑戰**：兩張照片之間必須進行「立體特徵比對（Stereo Matching）」，在遇到無紋理表面（如一面純白的牆或光滑圓球）時容易失效 [文獻 6, 7]。

### 流派 B：單眼幾何相似三角形法（Similar Triangles，論文 2）
* **原理**：在已知夾取物體先驗尺寸（例如工廠生產的標準撞球半徑 $R$ 為固定已知數值）的情境下，物體在相機感光元件上所佔的像素大小，與實際物理距離成嚴格的反比幾何關係。
* **優點**：只需要一顆普通的廉價 WebCam，運算量極低，不需高階顯卡 [文獻 2]。

### 流派 C：主動式深度感測器（RGB-D / 固態光達，論文 2）
* **原理**：相機本身主動向外發射肉眼不可見的光訊號（例如 Intel RealSense L515 採用紅外雷射微型振鏡光達），藉由測量光束往返物體表面的時間（Time of Flight, ToF），直接量測數以萬計點的三維座標，輸出緻密的 3D 點雲（Point Cloud） [文獻 2]。

### 📊 關鍵實證：500 mm 深度量測「黃金分界線」（論文 2 核心成果）

論文 2 針對堆疊球形物件進行了大量嚴謹的對比實驗，揭示了一條具高度實用價值的工程法則：

```
       0 mm               200 mm ~ 350 mm                 500 mm                     700 mm ~ 
        ├────────────────────────┼──────────────────────────┼───────────────────────────┤
        │      【近距離盲區】     │   【相似三角形法最優區】   │    【深度影像 (RGB-D) 最優區】 │
        │  距離太近導致相機對焦    │  幾何推算法誤差僅 1~4 mm   │  RGB-D 深度相機抗雜訊佳，    │
        │  或紅外線反射強烈過曝    │  深度相機易受光斑反射盲區  │  夾取成功率高達 100% ！       │
```

* **近距離（$Z < 500\text{ mm}$）**：
  * **相似三角形法**大獲全勝，深度量測平均誤差在 **$1 \sim 4\text{ mm}$** 以內。
  * **深度相機（RGB-D）** 反而容易因為距離過近，紅外光束過於集中產生強烈反射飽和，出現大片「深度數值為 0」的感測盲區。
* **遠距離（$Z > 500\text{ mm}$）**：
  * **相似三角形法**的誤差隨距離成倍放大（誤差攀升至 $7 \sim 13\text{ mm}$），在 $600\text{ mm}$ 時容易發生夾空或夾爪撞擊桌面的意外。
  * **深度相機（RGB-D）** 表現極度穩定，量測誤差收斂至 **$1 \sim 2\text{ mm}$**，夾取成功率達到完美 **100%** [文獻 2]。

## 2. 相機眼中的世界是歪的？相機標定（Camera Calibration）

初學者常誤以為「相機拍到的畫面就是真實世界的縮小版」，但實際上，光線穿過光學玻璃透鏡時一定會產生**鏡頭畸變（Lens Distortion）**（論文 6 深入探討）：
* **徑向畸變（Radial Distortion）**：像魚眼鏡頭一樣，影像邊緣線條向外凸起（桶狀畸變 Barrel）或向內收縮（枕狀畸變 Pincushion）。
* **切向畸變（Tangential Distortion）**：透鏡與感光晶片（CMOS）安裝時沒有完全平行所導致的偏心傾斜。

```
     【真實世界的直線網格】               【桶狀畸變 (Barrel)】               【枕狀畸變 (Pincushion)】
        ┌───┬───┬───┐                       ╭───┬───┬───╮                       ┌───┬───┬───┐
        │   │   │   │                      (    │   │    )                      │ ╲ │   │ ╱ │
        ├───┼───┼───┤       ──────>         ├───┼───┼───┤       ──────>         ├───┼───┼───┤
        │   │   │   │                      (    │   │    )                      │ ╱ │   │ ╲ │
        └───┴───┴───┘                       ╰───┴───┴───╯                       └───┴───┴───┘
```

### 內參矩陣（Intrinsics）與外參矩陣（Extrinsics）
相機標定（Calibration）就是為相機量身打造「專屬矯正眼鏡」的過程：
* **相機內部參數（$K$）**：屬於相機內在屬性，包含物理焦距 $(f_x, f_y)$、光學中心主點 $(c_x, c_y)$ 以及多項式畸變係數 $(k_1, k_2, p_1, p_2)$。一旦校正完成，只要不調焦距就終身固定。
* **相機外部參數（$[R \mid T]$）**：屬於相機在世界中的外在擺放位置，包含相機相對於世界或手臂底座的 **旋轉矩陣 $R$** 與 **平移向量 $T$**。
* **經典解法（張正友棋盤格校正法）**：拿一塊黑白相間、幾何間距絕對精準的棋盤標定板，讓相機從 15~20 個不同傾斜角度拍攝。演算法自動偵測棋盤內部的黑白交叉角點，反推求解出內參和畸變參數，成功將扭曲的影像還原為平直透視投影 [文獻 6, 7]！

## 3. 跨空間次元的橋樑：座標轉換與單應性矩陣（Homography）

要讓機器手臂夾到目標，必須完成一連串跨越不同「參考座標系（Frames）」的數學轉換接力賽：

```
  【影像像素座標系】             【相機光學座標系】             【機械手臂基座座標系】
      (u, v) [像素]     ──(相機內參反算)──> (Xc, Yc, Zc) [mm]  ──(手眼外參矩陣)──>  (Xb, Yb, Zb) [mm]
```

### 工程快速捷徑：單應性矩陣（Homography Matrix，論文 1）
如果目標物體都在同一個水平工作平台（例如平面輸送帶或桌面上）滑動，此時目標的物理高度 $Z$ 是恆定的已知常數！
論文 1 採用了極為精巧的工程降維技巧——**單應性映射（Homography Mapping）**：
$$\begin{bmatrix} X_b \\ Y_b \\ 1 \end{bmatrix} = \mathbf{H} \begin{bmatrix} u \\ v \\ 1 \end{bmatrix}$$
* **好處**：我們完全不需要建立複雜的 3D 立體幾何模型！只需要在桌面上選定 4 個已知物理座標點，比對它們在影像中的像素座標 $(u, v)$，就能直接求得 $3 \times 3$ 的單應性轉換矩陣 $\mathbf{H}$。
* 只要相機在畫面上看見目標的像素位置，乘上矩陣 $\mathbf{H}$，就能在 **0.001 毫秒內瞬間算出手臂基座座標 $(X_b, Y_b)$** [文獻 1]！

## 4. 動態目標抓取：抓「未來」而不是抓「現在」！

靜態取物時，手臂慢悠悠開過去也抓得到；但在工業自動化中，物體往往在輸送帶上持續移動。
這時會遇到致命的**「時間延遲問題（Latency Lag）」**：

$$\text{總時間延遲 } \Delta t = \text{相機曝光時間} + \text{AI 辨識耗時} + \text{座標運算耗時} + \text{手臂機構移動時間}$$

如果手臂朝著「相機拍下照片時的那個位置」抓過去，當夾爪抵達時，目標物早就滑走了幾公分，造成夾空！因此，**手臂必須預判物體在未來的落點**（論文 1 核心貢獻） [文獻 1]。

```
  時間 t0: 相機拍攝目標在 A 點 ──┐
  時間 t1: AI 運算完成 (花了 30ms)│
  時間 t2: 手臂開始揮動          ├────> 如果瞄準 A 點，手臂在 t3 抵達時必定夾空！
  時間 t3: 手臂抵達預定位置 ─────┘      因為物體此時早就滑到了 B 點！
```

### 1. YOLOv10 即時目標辨識與「目標鎖定機制」（論文 1）
* **超高幀率偵測**：採用最新一代的 YOLOv10 深度學習模型，具備無 NMS（Non-Maximum Suppression）延遲優勢，能在極低延遲下辨識輸送帶上的物件類別（如分辨寶特瓶 Bottle 或鋁罐 Can）。
* **目標鎖定防抖（Target Locking）**：如果輸送帶上同時出現多個瓶子，AI 每一幀檢測輸出的順序可能跳動，導致手臂大腦產生「選擇障礙（乒乓效應）」。論文 1 設計了距離連續性鎖定演算法，一旦鎖定特定 ID 的目標，便持續追蹤該目標直到成功夾取或移出邊界為止 [文獻 1]。

### 2. 機器人界的「預言家」：卡爾曼濾波器（Kalman Filter，論文 1）
卡爾曼濾波器是控制理論中的經典瑰寶，它在此處扮演兩大關鍵角色：**濾波抗噪** 與 **軌跡預言**。

```
                    ┌──────────────────────────────────────────────┐
                    │               卡爾曼濾波黃金雙環              │
                    └──────────────────────┬───────────────────────┘
                                           │
                    ┌──────────────────────┴──────────────────────┐
                    ▼                                             ▼
             【步驟一：狀態預測】                          【步驟二：量測更新】
          (基於等速度物理定律預推)                      (結合相機最新拍到的像素修正)
       • X_pred = X_prev + V * Δt                   • 計算相機觀測與預測值的殘差
       • 即使相機短暫 1~2 幀漏檢漏拍，              • 透過卡爾曼增益 (Kalman Gain)
         濾波器依然能平穩預推位置！                   壓制鏡頭像素抖動雜訊！
```

* **二維等速度運動模型（Constant-Velocity Model）**：
  狀態向量包含物體的 2D 位置與瞬時速度：$\mathbf{x} = [x, y, v_x, v_y]^T$。
* **抗漏檢（Occlusion Resilience）**：當物體被光影干擾或短暫被機械手臂擋住視線導致 YOLO 漏檢時，卡爾曼濾波器僅憑「物理運動慣性」就能持續預測目標下一步位置，完全不中斷追蹤 [文獻 1]！
* **精準引導抓取**：大腦根據手臂關節運動規劃所需的總耗時 $T_{\text{reach}}$，令卡爾曼濾波器直接預測 $t + T_{\text{reach}}$ 時刻的座標。手臂夾爪直接提前埋伏在物體前進路線的未來落點，優雅完成動態抓取 [文獻 1]！
