## 🧭 為什麼需要「視覺導引」？——機器手臂的「靈魂三問」

在傳統工業產線上，早期的機器手臂本質上是「盲人」：工程師寫好固定的移動座標（例如：從 A 點移到 B 點），手臂就日復一日、閉著眼睛精確揮動。
一旦輸送帶上的零件稍微歪了一度、或是堆疊的箱子滑落了幾公分，盲目揮動的手臂就會夾空甚至撞毀設備。

為了解決這個痛點，現代機器人學結合了**電腦視覺（Computer Vision）**與**機械控制（Robotics Control）**，賦予手臂像人類一樣「眼、腦、手」協調運作的能力。一套完整的視覺伺服系統，必須在數十毫秒內回答三個核心問題：

```
       【眼睛 Eye】                     【大腦 Brain】                    【骨骼與手 Hand】
  ┌───────────────────────┐        ┌───────────────────────┐        ┌───────────────────────┐
  │ 1. 我看見了什麼？     │ ──────>│ 2. 它在三維空間哪裡？ │ ──────>│ 3. 我的關節該怎麼轉？ │
  │    (物件辨識與分類)   │        │    (深度感知與預測)   │        │    (逆運動學與平滑抓取)│
  └───────────────────────┘        └───────────────────────┘        └───────────────────────┘
```

1. **我看見了什麼？（物件辨識）**：利用相機與深度學習演算法，在複雜雜亂的畫面中找出目標（例如分辨是寶特瓶、易開罐，還是圓球）。
2. **它在三維空間的哪裡？（深度感知與動態預測）**：相機照片只是 2D 平面，機器手臂必須知道精確的 3D 空間位置 $(X, Y, Z)$；若目標在移動，大腦還得預測它「幾秒後會在哪裡」。
3. **我的關節該怎麼轉過去抓，才不會晃動？（運動學與控制）**：知道了空間座標，各關節馬達要轉動幾度？加速度多大才不會產生劇烈震動？

## 💡 初學者必讀術語速查庫（Cheat Sheet）

在深入各章節之前，先掌握這幾個高頻詞彙，能讓閱讀事半功倍：

* **自由度（Degree of Freedom, DOF）**：手臂能獨立運動的關節數量。四軸手臂通常能完成平面定位加高低夾取；六軸手臂則能自由調整任意空間位置 $(X, Y, Z)$ 與姿態角（Roll, Pitch, Yaw）。
* **末端工具中心點（Tool Center Point, TCP）**：手臂最前端執行夾取、焊接或測量工具的工作焦點。
* **眼在手（Eye-in-Hand）**：攝影機直接固定安裝在機械手臂的最前端，隨著手臂運動而移動。
* **眼到手（Eye-to-Hand）**：攝影機架設在機械手臂外部的固定工作空間上方，以第三人稱視角俯瞰全局。
* **正運動學（Forward Kinematics, FK）**：已知「每個關節旋轉了幾度」，計算出「末端夾爪現在在空間的哪裡」。
* **逆運動學（Inverse Kinematics, IK）**：已知「目標物體在空間的座標」，反求「每個關節馬達必須轉幾度才能抵達」。
* **位置基準視覺伺服（Position-Based Visual Servoing, PBVS）**：先由相機影像計算出目標在 3D 空間中的物理座標，再以此物理位置驅動手臂前進。
* **視差（Disparity）**：同一個物體在左右兩個相機成像位置的水平像素差。離鏡頭越近，視差越大；離鏡頭越遠，視差越小。
* **單應性矩陣（Homography Matrix）**：將一個 2D 平面（如桌面）的像素座標直接映射換算到另一個 2D 平面（如手臂基座平面）的轉換矩陣。
* **卡爾曼濾波器（Kalman Filter）**：結合物理運動模型與實際觀測值，即時剔除相機跳動雜訊，並預測物體下一時刻位置的強大統計演算法。
* **同步定位與建圖（SLAM）**：機器人在完全未知的環境中，一邊移動繪製周遭地圖、一邊確定自身精確位置的技術。
